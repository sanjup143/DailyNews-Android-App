# DailyNews Android App

Modern Android News App built with Kotlin and MVVM architecture.

## Features

- Latest news
- Category-wise news
- Search news
- Bookmark articles
- Offline bookmark support
- Read full article in WebView
- Dark mode
- Shimmer loading effect
- Swipe refresh
- Retry/error handling
- Bottom navigation

## Tech Stack

- Kotlin
- MVVM Architecture
- Retrofit
- Room Database
- Hilt Dependency Injection
- Coroutines
- LiveData
- Navigation Component
- RecyclerView
- ViewPager2
- Material Design
